# Jungle Newsroom

A lean agent newsroom that tracks social media culture and trends (UK first, global when trends cross borders) and turns them into a daily update for each client desk.

One engine, one brief pack per desk:

- **Jungle desk** for Strategy and Data & Insight: prompts for thought leadership pieces and quick reactive ideas for Jungle's own social.
- **Client desks** (Disney UK, Disney Family UK, Muti UK, DFS, …) for the social and creative teams.

A shared crew scouts, tags momentum and fact-checks once each morning; each desk then adds one light step that filters and angles the day's stories with its own brief pack.

## In this repo

- `docs/agent-newsroom-principles.md`: the founding principles the newsroom is built on.
- `prototype/floor.html`: a clickable 3D mockup of the newsroom floor (crew characters, the morning run, seasonal themes). Example content only.
